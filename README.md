# CAD Engineering Portfolio

A collection of my CAD designs, documenting my progress in 3D modeling, mechanical design, and 3D printing using **Autodesk Fusion 360** and **FreeCAD**.

This repository serves as an archive of my learning process, independent projects, and design experiments, from simple models to more complex mechanical assemblies.

## Repository Structure

| Section | Description |
|---|---|
| **[01 — Learning & Tutorials](01-Learning-and-Tutorials/)** | Models created while learning CAD tools and techniques through tutorials |
| **[02 — Independent Designs](02-Independent-Designs/)** | Original designs, mechanical components, enclosures, and personal projects |
| **[03 — Design Development](03-Design-Development/)** | Prototypes, design iterations, experiments, and improvements |

## Tools & Software

- **CAD:** Autodesk Fusion 360, FreeCAD
- **3D Printing:** Anycubic Kobra 2 Neo
- **Slicing:** Anycubic Slicer Next
- **Documentation:** GitHub

## About This Repository

My goal is to continuously improve my CAD and engineering skills through hands-on learning and experimentation.

Each design is documented individually, with relevant CAD files, previews, and references where applicable.

This repository will continue to grow as I explore new modeling techniques and develop more advanced engineering projects.
